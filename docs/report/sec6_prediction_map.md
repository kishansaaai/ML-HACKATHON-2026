# 6. Geographical Visualisation Using Folium

Maps are generated by the project's own code and not drawn by hand. `scripts/make_prediction_map.py --trip 00000052 --part student_test` writes the interactive Folium map `reports/prediction_map_00000052.html` (code and HTML are committed); `scripts/make_eda_map.py` writes the EDA map (Figure 3); the evaluator UI draws the same kind of map from the API response (Figure 9).

**Layers, colours and markers (requirement 1).** Raw GPS observations are red dots (Figure 8) or blue dots (UI); the trip's road network is thin grey lines (only arcs inside the GPS bounding box plus a margin, to keep the file small); the reference route is a thick orange line, drawn only after the prediction and only for development trips; the predicted classifier + HMM route is a blue line (green in the UI), with start and end markers in the UI.

**Labels and legend (2).** A legend box in the lower-left corner names every layer with its colour. **Extent and zoom (3).** The map is centred on the median of the track at zoom 14 and the road network is clipped to the track's extent. **Comparison (4).** Raw GPS, the reference route and the predicted route overlay each other, so deviations are visible. **Layer control (5).** Every layer can be switched on and off from the control at the top right.

![Figure 8. Prediction map for student_test trip 00000052: raw GPS (red), road network (grey), reference route (orange) and predicted classifier + HMM route (blue), with legend and layer control. Reproduced by `scripts/make_prediction_map.py`.](docs/report/fig/prediction_map_00000052.png)

On this trip the predicted route follows the reference along the main road; the loop near the interchange is where the GPS wanders and where the route is least accurate. Trip 00000052 has classifier Top-1 0.9733 and HMM Top-1 0.9809, but its arc-set F1 is 0.8814 for the classifier alone against 0.6889 with the HMM (section 5.3), so this trip is also an example of the decoder adding arcs. Where the route has a break (time gap, no candidates or unreachable pair) it is drawn as separate polylines and never joined by a false line.
